## 페르소나별 화면 흐름 요약

```
페르소나 1 — 김보호 (보호자)
  시나리오 1-1: SCR-001 홈 → SCR-002 공고 등록 → SCR-003 제안 목록 → SCR-004 매칭 확정
  시나리오 1-3: SCR-005 케어 일지 수신 (SSE 실시간)
  시나리오 1-4: SCR-006 렌탈 신청 → SCR-007 내 렌탈 내역

페르소나 2 — 박시터 (시터)
  시나리오 2-1: SCR-008 AI 프로필 생성
  시나리오 2-2: SCR-009 공고 목록 → SCR-010 제안 입찰 → SCR-011 케어 일지 등록

페르소나 3 — 이탐색 (탐색형 보호자)
  시나리오 3-1: SCR-012 AI 챗봇 (시맨틱 탐색)
  시나리오 3-2: SCR-001 홈 → SCR-013 공고 검색

공통 마이페이지
  SCR-014 내 매칭 목록 · SCR-015 내 정보 수정
```
